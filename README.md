## ▫️  Características del Proyecto

* **Diseño **70%** original:** Diseñado para una buena experiencia de usuario.

* **Diseño Responsive:** Adaptado para dispositivos moviles, pantallas de escritorio y tablets.

* **Enfoque UX/UI:** Interfaz diseñada buscando una navegación clara, intuitiva y agradable para el usuario.

* **Interactividad:** Implementación de funcionalidades dinámicas mediante JavaScript.

* **Navegación estructurada:** Secciones organizadas para facilitar el acceso a la información personal y profesional.

* **Animaciones y efectos:** Uso de transiciones y efectos visuales para mejorar la experiencia de navegación.
